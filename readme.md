# Clase 1 - Variables, tipos de datos y control de flujo

## ¿En qué rama estás?

Estás en la rama `Clase_1`, que cubre los fundamentos absolutos de Python: variables, tipos de datos básicos, cadenas de texto, colecciones y control de flujo (bucles y condicionales).

## Cómo cambiar de rama

Para moverte a otra clase, usa el comando:

```bash
git checkout Clase_2
```

Sustituye `Clase_2` por el nombre de la rama a la que quieras ir.

## Contenido de esta clase

Los notebooks en la carpeta `/codigo` cubren:

**Variables y fundamentos:**
- I/O básico: `print()` e `input()`
- Variables, referencias y tipos de datos básicos (`int`, `float`, `bool`, `str`, `None`)
- Operadores aritméticos y lógicos
- Métodos de strings y f-strings
- Caracteres de escape (`\n`, `\t`)
- Colecciones: listas, tuplas, conjuntos y diccionarios
- Mutabilidad, inmutabilidad, `hash()` e `id()`
- Asignaciones aumentadas (`+=`, `-=`, etc.)
- Funciones integradas: `abs()`, `max()`, `min()`, `pow()`, `round()`, `len()`, `range()`

**Control de flujo:**
- Bucles `while` y cuándo usarlos
- Bucles `for` e iteración sobre colecciones
- Bucles anidados
- Condicionales `if`, `elif`, `else`
- Condicionales anidados
- Operador ternario

## Proyecto propuesto (~30 minutos)

**Mini calculadora de notas:**
Crea un programa que pida al usuario las notas de 4 asignaturas (entre 0 y 10), calcule la media, e imprima un resultado formateado indicando si ha aprobado (≥5), está en recuperación (3–4.9) o ha suspendido (<3). Muestra también la nota más alta, la más baja y cuántas asignaturas ha aprobado.
